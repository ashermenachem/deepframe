# Contributing to Deepframe

Thanks for looking closer. Open an issue describing the problem or idea before a large change.

1. Fork the repository and follow the README setup instructions.
2. Create a branch for your change.
3. Keep photo processing local, preserve keyboard access and reduced-motion behavior, and never infer missing metadata.
4. Run `npm test` and `npm run build`. Check narrow and wide layouts.
5. Open a pull request explaining the behavior change and how you tested it.

Use synthetic or consented test photos. Do not commit personal photos, GPS locations, or exported user reports. Report security concerns privately through the creator’s GitHub profile instead of posting sensitive files in public issues.
